File Handling

Practice Question On File Handling..!
Note: File handling in C allows you to create, read, write, and delete files. It is used to store data persistently and retrieve it when needed.

1.

Create a file and copy that file into another file.

Solution:

Output : 

Enter File1 Name: DATA.TXT

Enter Data:
Hello World! This is a file handling program.           Press Ctrt+S to stop entering and save

Enter File2 Name Where You Want To Copy Above Content or File:
COPY.TXT

Hello World! This is a file handling program.
Copy Success..!!
