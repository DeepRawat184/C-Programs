Iteration Control Structure (Nested Loops)

Practice Question On Nested Looping Programs..!
Note: Nested loops in C are loops that are placed inside another loop. The inner loop is executed completely for each iteration of the outer loop.

1.

Write a program print the pattern on the screen i.e. ?
11111
11111
11111

Solution:

Output : 

11111
11111
11111

2.

Write a program to print a right-angle triangle using stars.

Solution:

Output : 

*
* *
* * *
* * * *

3.

Write a program to print an inverted right-angle triangle using stars.

Solution:

Output : 

* * * *
* * *
* *
*

4.

Write a program to print a pyramid using stars.

Solution:

Output : 

    *
   ***
  *****
 *******

5.

Write a program to print an inverted pyramid using stars.

Solution:

Output : 

* * * *
 * * *
  * *
   *
